# Dry Bean Classification — Machine Learning Assignment 2

## a. Problem statement
Build and compare five supervised classification algorithms that predict the variety of a dry bean from numerical geometric measurements extracted from bean images. This is a seven-class classification problem.

## b. Dataset description
- **Dataset:** Dry Bean
- **Source:** UCI Machine Learning Repository, dataset ID 602
- **Official page:** https://archive.ics.uci.edu/dataset/602/dry+bean+dataset
- **Citation:** Dry Bean [Dataset]. (2020). UCI Machine Learning Repository. https://doi.org/10.24432/C50S4B.
- **Original size:** 13,611 instances and 16 numerical input features
- **Target:** `Class` (Barbunya, Bombay, Cali, Dermason, Horoz, Seker and Sira)
- **Feature names:** Area, Perimeter, MajorAxisLength, MinorAxisLength, AspectRation, Eccentricity, ConvexArea, EquivDiameter, Extent, Solidity, roundness, Compactness, ShapeFactor1, ShapeFactor2, ShapeFactor3 and ShapeFactor4.
- The dataset meets the assignment minimum of 12 features and 500 instances. UCI lists the dataset under a CC BY 4.0 license; retain attribution when redistributing.

## d. Models used and evaluation

The training script uses a stratified 80:20 train/test split with random state 42. Duplicate rows are removed before splitting. Scaling is included in the pipelines for Logistic Regression, KNN, Gaussian Naive Bayes and SVM; the Decision Tree uses median imputation without scaling.

The six metrics are calculated on the same held-out test partition:
- Accuracy
- Weighted one-vs-rest ROC AUC
- Weighted Precision
- Weighted Recall
- Weighted F1
- Matthews Correlation Coefficient (MCC)

Run `python train_models.py` to generate `model/metrics.json`. Copy the generated results into the table below only after running and verifying the experiment.
